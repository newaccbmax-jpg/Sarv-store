# بک‌اند فروشگاه پوشاک سرو

این پروژه با **Node.js 22.5 یا جدیدتر** و ماژول داخلی SQLite ساخته شده است؛ برای اجرای نسخه‌ی پایه به نصب پکیج npm نیاز ندارد.

## راه‌اندازی در VS Code

1. Node.js نسخه‌ی 22.5 یا جدیدتر را نصب کن.
2. این پوشه را در VS Code باز کن.
3. فایل `.env.example` را کپی و نام کپی را `.env` بگذار.
4. مقدار `ADMIN_KEY` داخل `.env` را با یک کلید خصوصی و طولانی عوض کن (حداقل ۲۴ کاراکتر). برای ساخت کلید تصادفی می‌توانی این دستور را در ترمینال اجرا کنی و خروجی را جایگزین مقدار قبلی کنی:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

5. ترمینال VS Code را باز کن و اجرا کن:

```bash
npm run dev
```

6. فروشگاه: `http://localhost:3000`
7. پنل مدیریت: `http://localhost:3000/admin.html`

برای توقف سرور، در ترمینال `Ctrl + C` را بزن.

## چه چیزهایی به بک‌اند وصل شده‌اند؟

- فهرست محصولات از SQLite خوانده می‌شود.
- سفارش‌ها با قیمت‌هایی که سرور خودش محاسبه می‌کند ذخیره می‌شوند؛ قیمت ارسالی مرورگر قابل اعتماد نیست.
- کوپن نمونه‌ی `SARV10` در سمت سرور اعتبارسنجی می‌شود.
- شماره‌های خبرنامه در دیتابیس ذخیره می‌شوند.
- پنل مدیریت امکان مشاهده‌ی سفارش‌ها، تغییر وضعیت، تغییر قیمت و افزودن یا حذف محصول را دارد.

## نکات مهم

- دیتابیس به‌صورت خودکار در `data/sarv-store.db` ساخته می‌شود. این فایل را حذف نکنی؛ اطلاعات سفارش‌ها و محصولات آنجاست.
- این پروژه درگاه بانکی ندارد و ثبت سفارش به معنی پرداخت نیست.
- این نسخه برای توسعه‌ی محلی و یادگیری است، نه انتشار مستقیم در اینترنت. قبل از انتشار عمومی باید HTTPS، پشتیبان‌گیری، محدودسازی درخواست‌ها، سیاست حریم خصوصی، مدیریت امن کاربران و درگاه پرداخت معتبر اضافه و بررسی شوند.
- کلید مدیریت را با کسی به اشتراک نگذار و فایل `.env` را منتشر نکن.
- داده‌های محصولات اولیه نمونه هستند و قبل از فروش واقعی باید نام، مشخصات، قیمت و تصاویر واقعی را جایگزین کنی.
